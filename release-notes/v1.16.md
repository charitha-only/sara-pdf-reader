# Sara PDF Reader v1.16

Office viewing and zoom controls.

- New Office documents open in Fit width so wide Word pages and Excel sheets are visible across the screen. Existing saved view settings still take precedence.
- Fit width and Fit page display the effective renderer percentage. Word, Excel, PowerPoint and legacy/text viewers report their applied CSS scale through the existing local bridge; invalid or non-finite reports are ignored.
- Zoom buttons step from the currently displayed scale instead of treating every fit as 100% and jumping to 125%. Added 10% and 25% manual levels for wide sheets; manual zoom is bounded to 10–300%. Fit modes can still go smaller to show a very wide document.
- Zoom buttons disable at their respective limits, while loading/restoring, and while a zoom command is pending. Low manual zoom settings are retained in reading data and manual backups.

Tests exercise real Word/Excel shell zoom handlers with bounded layout fixtures, width/page fits, viewport-size changes, invalid renderer reports, zoom stepping and saved-state retention. Existing Office engine/print/resource checks remain part of release validation.

Original files, authored table/page geometry and existing WebView zoom/pan remain intact. No new dependencies, permissions or Internet access are added. Complex Office/legacy layout fidelity remains approximate; physical-phone/printer testing was not performed. v2.0 editing remains disabled.

Release checks: 83 app tests passed; source analysis clean. Universal/ARM64/ARMv7 APKs passed identity, signing, ABI, offline-permission, 16 KB ZIP-alignment and APK security checks. Physical-phone/printer testing was not performed.
