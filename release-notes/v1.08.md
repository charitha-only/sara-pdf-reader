# Sara PDF Reader v1.08

Android build 13. Android 8.0 or later.

- Explicit white Get Started text and arrow, independent of inherited button/theme foreground colours.
- PDF, image and camera-scan printing through Android print services, with preview and Save as PDF. Android controls available copies, page ranges, paper and orientation options.
- Office Print opens the Android WebView print adapter. Excel prints the current sheet and selected print-range/full-sheet view. Other sheets can be selected before printing. Preview fidelity remains subject to the document renderer.
- Print media styles remove reader tabs/navigation, reset on-screen zoom and prevent the screen viewport from clipping printed content.
- Local Office navigation now requires the private HTTPS workspace path and rejects alternate ports, user-info URLs and encoded traversal attempts.
- No new camera/media permissions or Internet permission. The printing plugin uses a non-exported file provider; documents are handed only to the Android print workflow chosen by the user.

Physical printer output is not yet verified. Printer availability and options depend on the installed Android print service. Complex Office layout may differ from Microsoft Office. Existing files are not edited by printing.

Security review also restricted the sharing provider to its camera/share cache directories, blocked incoming file:// paths outside public external storage, and bounded received batches to 256 MB. App settings and private library directories are not exposed through the sharing provider.

Verification: 51 app tests and 40 document/security engine tests passed; final analysis clean. Signed API36 emulator checks verified the visible welcome label/arrow, PDF print preview and settings, printing only page 2 from a two-page PDF with selectable text preserved in the one-page output, Excel preview printing to a readable two-page PDF, and rejection of an external intent targeting a private app file path. All three signed APKs passed publisher/version/ABI/offline-permission and 16 KB ZIP-alignment checks. 117 dependency versions returned no OSV advisory matches at review time. Physical printer output remains pending.
