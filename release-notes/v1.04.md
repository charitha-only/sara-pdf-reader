# Sara PDF Reader v1.04

Android build 9. Android 8.0 or later.

- The library + button opens the phone camera. Capture a full-resolution photo, review/rotate it and apply optional grayscale scan contrast. Export a single-page PDF, PNG or JPEG; save with the Android destination picker, share or add a copy to the library. Importing existing files remains available in the library.
- Camera capture uses the installed Android camera app and a temporary, narrowly scoped content URI. Sara does not request broad camera/storage access. Cancelling leaves the library unchanged. No document-edge detection, perspective correction or multi-page scan is claimed.
- Office readers expose 50%, 75%, 100%, 125%, 150%, 200% and 300% scales, fit width, and readable original size for new documents. Saved scale choices persist. Native touch gestures reach the document WebView for pinch zoom and panning.
- First-open setup explains file/destination access and how to choose Sara as the default PDF viewer through Android. Android controls default app selection; Sara cannot silently replace an existing default.

Image export normalizes photo orientation, resizes to a maximum 2400-pixel edge and recompresses JPEG at quality 92. PDF contains the processed image on one A4 page. Original capture metadata is not deliberately retained in exported images.

Physical-phone camera verification remains pending because USB debugging was unavailable. Compilation and automated conversion checks do not establish camera compatibility with every phone. Older releases keep their downloads.

Verification: application suite 40 passed (including capture rotation, scan contrast, PNG/JPEG/PDF conversion and invalid input); Flutter analysis has no issues. Android signed release compilation passed. Native-camera and OEM-device limits are tracked separately.

Signed emulator smoke check: first-open setup, + launching Android camera, shutter/confirmation, photo preview and PDF system-save destination flow passed. Physical-phone camera testing remains pending.
