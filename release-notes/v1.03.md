# Sara PDF Reader v1.03

EPUB reading, offline Sinhala/English scanned-text reading, better Office previews and more reading controls.
ARM64 **56.2 MB**, ARMv7 **50.1 MB**, universal **125.4 MB** (MiB).
Android build 8. Android 8.0 / API 26 or later is required.

## Updates

1. **Word previews:** bundled Sinhala fallback fonts for common Office font names and unknown document font fallbacks; embedded/authored fonts stay first. Added endnote rendering. Original sizes, margins, tables and explicit page breaks remain authored by the document; complex Word pagination is approximate.
2. **Excel previews:** cached bar, line, pie and doughnut chart previews (or cached worksheet values when chart caches are absent); common numeric/text conditional rules and RGB scales/data bars. Go to a cell by address. Unsupported effects and chart types are identified; formulas are not recalculated.
3. **Scanned PDFs:** read a page or the whole PDF using bundled Sinhala, English or combined OCR. Search/highlight/copy recognized text, return to the original page, cancel and continue completed pages. Original PDFs remain unchanged. Recognition can be inaccurate; compare uncertain words with the original.
4. **PDF navigation:** document contents/outline navigation and embedded internal links. External link addresses can be copied.
5. **EPUB books:** import/open unencrypted reflowable EPUB 2/3 text/image publications; chapter contents, book search, adjustable text size/line spacing, paper/sepia/night appearance, and saved chapter/scroll position. Publication scripts and remote resources never run. Fixed-layout, DRM and multimedia are not supported. Obfuscated publication fonts are ignored in favor of bundled fonts.
6. **Library organization:** virtual folders and comma-separated tags from a document's menu. Folder filters persist, search includes tags/folders, and backups keep organization metadata.
7. **Reading controls:** full-screen system bars, automatic/portrait/landscape rotation and keep-screen-on controls. Choices persist; leaving the reader restores normal display behavior. Available across PDF, Office, text, images and EPUB.
8. **Recovery and performance:** a previous valid library snapshot survives index corruption, existing v1.02 metadata remains compatible, and image decoding/cache use is bounded. OCR text caches are removed when clearing the library.

## Downloads and updates

ARM64 is recommended for most modern phones; ARMv7 is for 32-bit Android. A universal APK is available when the architecture is unknown. All variants use the same application ID, publisher certificate and Android build 8. Install over v1.02 to update. Older GitHub releases retain their downloads. The Sara logo is also available as a transparent PNG.

Release builds request no Internet permission. Documents, OCR models, fonts and reading state stay local. GitHub update links open in an external browser.

## Verification and limits

Application suite: 38 passed. Office engine suite: 39 passed. JavaScript checks cover four chart types, missing chart-cache fallback, escaping/unsupported charts, conditional rules and cached range statistics. Four new Android integration scenarios passed for EPUB/resume/display controls, PDF outlines/internal links, folder/tag persistence, and real raster-page English/combined Sinhala OCR. Three previous Office/text/PDF device scenarios passed as regression checks.

Signed v1.02 → v1.03 update retained original file hashes, favourites, bookmarks and reading state without uninstalling. The signed release opened synthetic Word/Sinhala, Excel charts/formatting and EPUB documents through Android content-URI intents. Final assets, signatures, versions, offline permissions, ZIP/64-bit ELF alignment and stripped native debug sections are verified. No physical Android phone was detected over USB in this run; physical-phone validation remains pending. Emulator results do not establish compatibility with every phone.

EPUB import: up to 40 MB compressed, 1,500 spine chapters, 8 MB of text and 32 MB retained image resources; basic reflow rather than publisher CSS fidelity. Office limits remain documented in the README. Advanced chart types, formula-based conditional formatting and exact Microsoft Office layout are outside this release.
