# Sara PDF Reader v1.15

Offline camera scan quality improvements.

- Adaptive B&W text processing uses local lighting and contrast, with soft transitions around text edges. This improves readability across unevenly lit receipt/document pages while retaining solid dark ink. Both the scan toggle and image-cleanup B&W preset use the same processing.
- Clean PNG exports process the decoded image directly, removing intermediate JPEG encode/decode cycles that could damage fine strokes and coloured stamp edges. JPEG exports still use their selected compression settings.
- Camera photo reduction and shadow estimation now use area averaging to reduce aliasing in fine lines. Cleanup previews use JPEG quality 94.
- The scan toggle is labelled B&W text, with a hint to turn it off when colours matter. Clean colour and the retained original remain available; source gallery files are unchanged.

Processing stays offline and on-device, with no new permissions, network services, dependencies or model downloads. Local B&W statistics are capped at a 480-pixel edge (about 5 MB of temporary numeric maps), within the existing 2400-pixel scan-page limit.

Synthetic regression cases cover thin low-contrast strokes under uneven light, solid dark areas, stamp colour, lossless clean PNG export and single-pixel/blank pages. A synthetic receipt comparison was visually reviewed. This cannot recover details lost to motion blur, glare or clipped exposure; physical-phone testing was not performed. v2.0 editing remains disabled.

Release checks: 81 app tests passed; source analysis clean. Universal/ARM64/ARMv7 APKs passed identity, signing, ABI, offline-permission, 16 KB ZIP-alignment and APK security checks. Physical-phone/printer testing was not performed.
