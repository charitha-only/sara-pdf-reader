# Sara PDF Reader v1.05

Android build 10. Android 8.0 or later.

- Add up to 20 camera pages to one scan, select a page, move it earlier/later or delete it. Cancelling the next camera capture keeps existing pages.
- Manually crop the selected page with four edge controls, a visible selection rectangle, Reset, Apply and Cancel/back. Rotation and scan contrast remain per-page. Crop preserves a color baseline so contrast can still be toggled.
- PDF Save, Share and Add to library include all pages in the displayed order. PNG/JPEG exports only the selected page, as explained on screen.
- Scans are bounded to 20 pages and a 60 MB draft budget. Each captured photo is normalized/resized to at most 2400 pixels on its longest edge. A4 PDF pages preserve aspect ratio and orientation.

Crop is rectangular and manual. Automatic edge detection, perspective correction and OCR text layers are not included. The scan draft is held in memory; save or add it to the library before leaving the scanner. Physical-phone validation remains pending.

Verification: 42 application tests passed, including crop dimensions, three-page PDF output, page-count limits and prior export/reader regressions.
