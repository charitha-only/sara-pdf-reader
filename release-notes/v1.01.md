# Sara PDF Reader v1.01

First GitHub APK release of Sara PDF Reader.

## Updates

- Renamed the application to **Sara PDF Reader**.
- Set the visible application version to **v1.01** (Android build 6).
- Reader-first interface; editing, file creation and conversion tools remain
  disabled for a later version.
- Offline PDF reading with zoom, search, bookmarks, thumbnails and fit modes.
- Offline Word, Excel and PowerPoint previews; text and image viewing.
- Sinhala/English interface controls and original-file sharing.
- Public MIT-licensed source, documented format limits and versioned APK downloads.

## Download and install

Download **Sara-PDF-Reader-v1.01.apk** from the release assets below.
Android 8.0 / API 26 or newer is required. The APK uses the same publisher
signing certificate and application ID as the previous Pageflow build, so
compatible existing installations can update without a separate app install.
The release requests no Internet permission.

Office rendering is approximate: fonts, complex objects and pagination can
differ. Spreadsheet charts/pivots/conditional formatting are not rendered;
legacy PPT supports text preview. See the README format table for full limits.

## Verification

Application tests: 32 passed. Office engine tests: 39 passed. The renamed
welcome screen also passed the existing accessibility checks. The baseline
reader had offline Android and receiving-app sharing checks; these are not
an exhaustive guarantee for every document. Release APK signature, version,
permissions and 16 KB ZIP alignment are checked before publishing.
