# Sara PDF Reader v1.09.4

Stability update; physical-phone testing is excluded from this release.

- EPUB reading position is restored after the actual chapter list has laid out, instead of before the asynchronous book view exists. Chapter navigation resets and saves the new chapter position after layout.
- Office zoom choices wait until the viewer is ready, catch failures, and update the displayed scale only after a successful change. The fit menu uses the same guarded path as zoom buttons.
- Includes the v1.09.3 logo animation and all previous scanning/reader features.

Checks: app regression tests and source analysis; signed APK identity/security checks before publication. Physical-phone/printer verification remains pending. Office rendering remains an approximation for complex documents.

Release checks: 66 app tests passed; source analysis clean. Universal/ARM64/ARMv7 APKs passed identity, signing, ABI, offline-permission, 16 KB ZIP-alignment and APK security checks. Physical-phone/printer testing was not performed.
