# Sara PDF Reader v1.09.1

Android build 15. A patch release; existing reader and printing features remain available.

- The + button opens a scrollable menu: Documents, Images, Camera / scan, Gallery photos to scan, and Resume saved scan. Camera access starts only after choosing Camera.
- Camera scans automatically reduce uneven paper lighting on the phone, without uploading photos or downloading a model. Auto clean lets you compare against the retained original scan baseline before saving. The choice survives draft recovery, rotation and cropping.
- Cleanup estimates local paper illumination while retaining dark lettering and colour. Processing runs in an isolate, with bounded image dimensions and a small background-estimation buffer. JPEG quality is 92 at up to 2400 pixels on the longest edge; PNG and multi-page PDF export remain available.
- Existing reviewed paper-corner detection/crop can remove dark surrounds. Review every result: deep shadows, glare, blurred text and non-paper photographs cannot be perfectly restored. No newly trained AI model is claimed.
- No network permission or new dependency. Existing private storage, backup exclusions, file-opening and sharing protections remain enabled.

Physical-phone/printer testing remains pending. Validation: 59 app tests passed and source analysis found no issues. An additional final scan regression run passed 15 tests. Tests cover source-menu routes, deep-shadow correction, dark text/coloured stamp retention, thin and oversized images, and cleanup/original draft recovery. The signed API36 emulator release opened the source menu, launched Camera, captured and automatically cleaned a photo, retained separate original/preview hashes, toggled original comparison, rotated the page and restored the saved draft after a cold launch. All three APKs passed signing/version/ABI/offline-permission/16 KB ZIP-alignment and APK security checks. Dependency versions are unchanged from v1.09.
