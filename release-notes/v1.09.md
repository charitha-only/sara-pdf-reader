# Sara PDF Reader v1.09

Android build 14. Android 8.0 or later. Includes v1.08 printing and welcome-button fixes.

- Scan Image cleanup offers brightness, contrast and optional uneven-shadow reduction, with Preview, Reset, Apply and cancel/back. Processing runs off the UI thread. Applied cleanup is included in the private recoverable scan draft; original Gallery files are unchanged.
- PDF Rotate view 90° rotates the reader without modifying the PDF. Page, view rotation and fit width/page preferences are restored per document.
- Library bulk rename applies a numbered prefix to selected document display names, preserves extensions and avoids existing names. Original files are not renamed. Existing multi-select/share remains available; the selection toolbar scrolls on narrow screens.
- Import and Settings header controls now expose clear accessible labels/tooltips.
- Excel preview work is bounded to 60,000 cells per sheet, 250,000 cells per workbook and the first 100 sheets, within the existing 3,000-row/200-column limits. Merged-cell ranges are clipped to the preview and have an explicit work budget, including overlapping/pathological ranges. Limit notices remain visible; printing a truncated preview requires acknowledgement.
- Automatic Android backup is disabled, with explicit cloud/device-transfer exclusions for app-private data; user-selected manual backup/export remains available. Cleartext network traffic is explicitly disabled.
- Incoming document work is limited to two pending native imports so repeated external intents cannot grow an unlimited work queue. v1.08 private-path, share-provider and offline WebView protections remain in place.

Limits: cleanup may alter colours/details and needs visual review; Reset applies before committing an adjustment. Office layout is approximate, especially complex/legacy files; cells outside preview budgets remain in the untouched original. Real-phone and physical-printer verification remain pending.

Verification: 55 app tests and 40 document/security-engine tests passed; source analysis clean. JavaScript checks passed for chart/conditional previews, print ranges and hostile resource cases: a full-size worksheet range, 10,001 overlapping full-sheet merges, and oversized print ranges sharing the workbook budget. The signed API36 release restored page 2/90-degree view rotation/fit-page after relaunch, retained four bulk-renamed display names with original file paths unchanged, applied brightness/shadow cleanup and restored the changed two-page draft after relaunch, and opened two-page scan print preview. Current-process logs showed no fatal/unhandled/controller/overflow errors. PDF page-range print and Excel print outputs were validated in v1.08; an additional supplied wide Excel example retained all 72 expected text values, including right-edge values, and was visually checked with all six machine columns visible. Personal documents and screenshots are not included in release assets.

All three APKs passed signing/version/ABI/offline-permission/16 KB ZIP-alignment checks and the APK security verifier, including non-debuggable builds, automatic backup/cleartext disabled, explicit backup/transfer exclusions, restricted app-share paths and the final spreadsheet/print budget guards. Dependency versions remain identical to the scoped v1.08 OSV audit. Physical-phone and physical-printer tests remain pending.
