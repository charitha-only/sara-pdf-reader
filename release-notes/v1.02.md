# Sara PDF Reader v1.02

Reader improvements, a new cyan/pink Sara logo, and smaller architecture-specific downloads.
ARM64 **53.9 MB**, ARMv7 **47.9 MB**, universal **122.9 MB** (MiB).
Android build 7. Android 8.0 / API 26 or later is required.

## What's new

1. Word and Excel previews wait for fonts/images before fitting. Choose fit width or original size; wide spreadsheets can scroll horizontally. Search spans workbook sheets.
2. Open documents directly from File Manager and sharing apps through Android Open with and Share. Files are copied into private app storage.
3. Sinhala/English PDF search highlights matches, shows progress, and offers next/previous and cancel. Office search navigates matching text/cells across sheets.
4. Resume text scroll positions and Office page/sheet/scroll/zoom mode; PDF page resume remains available. Backup includes the new reading positions.
5. Library search is debounced; filters and sorting persist. Favourites remain available, and large libraries load in batches.
6. Per-file import progress/cancel, clearer size/encryption/damage errors, and Office retry/cancel/timeouts.
7. Lower PDF rendering memory budget and improved loading states. ARM64 and ARMv7 APKs retain offline resources while avoiding unused architecture libraries.
8. Settings links to the latest GitHub release, update notes, and all previous versions.

The new Sara logo is included in the launcher/splash and as a downloadable PNG.

## Downloads

- **ARM64 APK**: recommended for most modern Android phones.
- **ARMv7 APK**: for devices running 32-bit Android.
- **Universal APK**: includes ARM64, ARMv7 and x86-64; use if unsure.

Install over the previous release to update; application ID and signing certificate are retained. Older releases keep their separate download links. Release builds request no Internet permission; GitHub links open in an external browser.

## Verification and limits

Application suite: 32 passed. Office engine suite: 39 passed. New reading-state and affected backup/progress/password checks: 6 passed. Three Android integration scenarios passed for synthetic Office rendering/search/resume, read-only Sinhala text search/resume, and native PDF match navigation/cancel. Final signed APK opened synthetic PDF and DOCX through Android Open with and XLSX through Share, offline. All APKs passed signature, version, permissions and 16 KB ZIP alignment checks; 64-bit native libraries retain 16 KB ELF alignment and stripped debug information.

Office previews remain approximate: missing fonts, complex objects and pagination can differ. Charts/pivots/conditional formatting and formula recalculation are not supported; legacy PPT is text preview. Editing is deferred to a future version. See the README for format and size limits.
