# Sara PDF Reader v1.07

Android build 12. Android 8.0 or later.

- Office viewing: visible zoom out/in, percentage, Fit width and 100% controls; scaling now updates the document layout and horizontal scroll area. Excel opens authored contiguous print ranges when available, with Show full sheet / Show print range controls. Search and cell navigation retain access to the full sheet.
- Scan draft recovery: pages, order, selected page, crop/rotation and contrast auto-save in private app storage. Reopening resumes the draft. A validated previous snapshot can recover a corrupt current manifest. New scan explicitly discards the draft; clearing the library also clears it.
- Page-edge suggestions: Auto crop / straighten suggests four corners for bright paper on a contrasting background. Review/adjust corners by dragging or using sliders. Ambiguous images keep manual corner selection available.
- Perspective correction: four-corner projective rectification straightens an angled photo; manual rectangular crop and rotation remain available.
- Searchable scans: optional offline Sinhala / English / combined OCR adds invisible selectable/searchable text to exported PDFs. The photographed page remains visible unchanged. Progress and cancellation are supported. Empty recognition prompts a language change or image-only export.
- Gallery to scan: select multiple photos from the + menu or scan toolbar; import within a 20-page / 60 MB draft budget, reorder/crop/straighten them, then export one PDF. PNG/JPEG exports the selected page. Originals are not modified.

Limits: edge detection is a suggestion, not a guarantee; review the page corners. OCR accuracy depends on language, lighting, resolution and handwriting. Recognized text may need correction in another editor. Office previews use open-source rendering and may differ from Microsoft Office, especially legacy DOC/PPT and complex floating layouts. Photo imports support formats decodable by the bundled image library; unsupported/oversize files are skipped with a count.

Physical-phone camera, permission, receiving-app and device-specific performance checks remain pending because no phone connection was available. Emulator checks do not certify every Android device. iOS and document editing remain deferred.

Verification: 51 app tests and 39 document-engine tests passed; final source analysis clean. Targeted draft recovery/UI checks also passed after storage hardening. API36 Android integration verified a two-page offline OCR export: searchable text was extracted from both pages and rendered pixels exactly matched the image-only PDF. A private integration test opened the four supplied Word/Excel examples and verified search, 200% zoom and horizontal panning. JavaScript regression checks covered authored print ranges, merged cells, full-sheet preservation, four chart types and conditional formatting; both supplied Excel examples retained styled sheets with 43/41-row print previews. Personal test documents are not included in this repository or release assets.

Signed-release API36 smoke checks also passed: Camera/Photos system permission prompts, selection of two Gallery photos, reviewed corner suggestions and Apply, Android Save as to Downloads, independent verification of the saved two-page PDF, restoration of both scan pages after force-stop/relaunch, and Android share-sheet launch. No message was sent to a receiving app. All three APKs passed publisher identity, version/build, offline-permission, ABI and 16 KB ZIP-alignment checks.
